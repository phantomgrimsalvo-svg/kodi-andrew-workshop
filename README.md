# Andrew's Kodi Workshop

Public GitHub copies of Andrew Webber's personal Kodi forks. Kodi cannot install from Cursor Origin URLs, so these repos exist so **any browser or Kodi box can download the zips with no login**.

These are **personal forks only**. They are not official releases and must not be PRed back to jurialmunkey or dobbelina.
